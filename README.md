# Naila Sabahat — Personal Portfolio

A dark blue, space-themed portfolio built with plain HTML, CSS, and JavaScript. No installation, build step, paid service, external fonts, or API keys are needed.

Demo: https://sabahatnaila-tech.github.io/demo-web/

## Preview on your computer

Extract the ZIP, then double-click `index.html`. Keep `index.html`, `styles.css`, `script.js`, and `favicon.svg` together in the same folder.

## Host on GitHub Pages — browser method (Mac and Windows)

1. Sign in at https://github.com and create a new **public** repository called `portfolio` (or another name you choose). Add a README to initialize the repository.
2. Open the repository. Select **Add file → Upload files**.
3. Upload the extracted website files, not the ZIP and not the enclosing folder. `index.html` must be visible at the repository's top level alongside `styles.css`, `script.js`, and `favicon.svg`. You can also upload this README. The empty `.nojekyll` file is included if you use Git; this plain HTML site also works without it.
4. Select **Commit changes**.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Select the **main** branch and **/(root)** folder, then **Save**.
8. Wait for the deployment to finish. Return to **Settings → Pages** and open the site link GitHub displays. The usual project URL is `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`. Replace the username and repository name with your actual values.

For a root website URL, create a repository named exactly `YOUR-GITHUB-USERNAME.github.io` instead. Never assume the LinkedIn username is your GitHub username.

Official GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit in VS Code

- Open the extracted folder in VS Code.
- **index.html:** name, introduction, background, teaching details, skills, and LinkedIn URL. Search for `nailasabahat010` to update all three LinkedIn links together.
- **styles.css:** colors, spacing, layout, planet illustration, and phone/tablet breakpoints. Theme colors are at the top under `:root`.
- **script.js:** mobile menu and three interactive demos.
- **favicon.svg:** browser tab icon.
- Save your changes and refresh `index.html` in your browser. Upload the changed files to GitHub and commit again to update the live site.

## Content to review before publishing

This first version uses the professional background supplied in your conversations: computer science graduate, co-founder, programming instructor, and Chicago-area location. Review the biography and every listed skill for accuracy and currency before making the site public. Add your startup name, professional photo, resume, and verified project links if desired.

The three featured activities are working illustrative teaching demos created for this portfolio. They are described as demos, not prior client projects. All three run in JavaScript in the browser, including the sorting lab inspired by Python teaching concepts. Contact buttons open LinkedIn; there is no email form or backend.

## Included interactions

- Mobile navigation and section links.
- Bubble-sort lab: step, sort, and shuffle.
- Number game: 1–20, higher/lower hints, five attempts, restart.
- Rover exercise: queue directions, undo, run, reset, boundary detection, goal detection.
- Keyboard-accessible dialogs with Escape-to-close, visible focus styles, reduced-motion support, and a skip link.

No tracking scripts or external asset dependencies are included.
